# Examples

Example workflows will be added after the first stable GUI scenario is finalized.

For now, use the GUI:

1. Select an input PNG image.
2. Select an output PNG image.
3. Enter text.
4. Use the default RGB/1-bit parameters.
5. Click **Embed text**.
6. Remember the payload size, seed, bit count and channels.
7. To extract, select the output image as input, enter the same parameters and click **Extract text**.
