# Параметры стеганографии

## Базовые параметры (применимы в обоих режимах)

| Параметр | Описание |
|----------|----------|
| **Бит на канал** | Количество младших бит, используемых в каждом цветовом канале (1–4). |
| **Seed** | Случайное зерно для перемешивания; `0` – без перемешивания. |
| **Каналы** | Какие цветовые каналы (R,G,B,A) используются. |
| **Размер полезной нагрузки** | Количество байт для извлечения (должно совпадать с исходным размером). |

## Параметры умного режима

| Параметр | Описание |
|----------|----------|
| **Режим** | *Uniform* или *Smart*. |
| **Размер окна** | Размер квадратного окна (3,5,7,9,11,13) для расчёта дисперсии. |
| **Метрика дисперсии** | *Яркость* (дисперсия Y-канала), *Поканальная* (отдельная дисперсия по каждому каналу), *Сумма* (сумма поканальных дисперсий). |
| **Порог** | Минимальное значение дисперсии; слоты ниже порога отбрасываются. |
| **Применить перемешивание после сортировки** | Если включено, отсортированный список перемешивается с использованием seed. |

## Как работает извлечение

1. Декодер строит точно такой же список слотов, используя заданные параметры.
2. Считывает биты из изображения в этом порядке.
3. Собирает байты и возвращает полезную нагрузку.

**Всегда записывайте все параметры после внедрения!**  
Интерфейс показывает их в строке состояния – скопируйте и сохраните.
