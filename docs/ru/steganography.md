# Параметры стеганографии

## Базовые параметры (применимы в обоих режимах)

| Параметр | Описание |
|----------|----------|
| **Бит на канал** | Количество младших бит, используемых в каждом цветовом канале (1–4). |
| **Seed** | Случайное зерно для перемешивания; `0` – без перемешивания. |
| **Каналы** | Какие цветовые каналы (R,G,B,A) используются. |
| **Размер полезной нагрузки** | Количество байт для извлечения. Если при встраивании был записан заголовок размера — определяется автоматически. |

## Параметры умного режима

| Параметр | Описание |
|----------|----------|
| **Режим** | *Uniform* или *Smart*. |
| **Размер окна** | Размер квадратного окна (3,5,7,9,11,13) для расчёта дисперсии. |
| **Метрика дисперсии** | *Яркость* (дисперсия Y-канала), *Поканальная* (отдельная дисперсия по каждому каналу), *Сумма* (сумма поканальных дисперсий). |
| **Порог** | Минимальное значение дисперсии; слоты ниже порога отбрасываются. |
| **Применить перемешивание после сортировки** | Если включено, отсортированный список перемешивается с использованием seed. |

## Что именно встраивается

Движок стеганографии работает с полезной нагрузкой как с непрозрачным потоком байтов и не анализирует её содержимое. Пользовательский текст может быть обёрнут двумя необязательными слоями:

```
[ 4-байтный заголовок размера ]   ← необязательно, --header / Настройки
[ RFP1-контейнер | открытый текст ]   ← зависит от того, включено ли шифрование
```

Оба слоя с точки зрения стеганографии — просто байты.

## Заголовок размера

Если включён, при встраивании перед данными записывается 4-байтное big-endian число — длина фактической нагрузки. При извлечении декодер сначала читает первые 4 байта, затем указанное количество байт. Если заголовок выключен, размер вводит пользователь.

Заголовок размера не зависит от шифрования: возможны любые из четырёх комбинаций (заголовок вкл/выкл × шифрование вкл/выкл), но **режимы встраивания и извлечения должны совпадать**.

## Как работает извлечение

1. Декодер строит точно такой же список слотов, используя заданные параметры.
2. Считывает биты из изображения в этом порядке.
3. Собирает байты и возвращает полезную нагрузку.

**Всегда записывайте все параметры после внедрения!**  
Интерфейс показывает их в строке состояния – скопируйте и сохраните.

Для **зашифрованных** нагрузок шифр, KDF, число итераций, соль и IV читаются из самого контейнера — воспроизвести нужно только пароль.
