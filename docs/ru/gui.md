# Использование графического интерфейса

## Расположение окна

- **Левая панель**: выбор изображений, параметры стеганографии, текстовая нагрузка, кнопки действий, настройки предпросмотра.
- **Правая панель**: предпросмотр изображения с различными режимами отображения.

## Пошаговое руководство

### Внедрение

1. **Входное изображение** – выберите файл PNG/BMP/TIFF.
2. **Выходное изображение** – укажите куда сохранить стего-изображение.
3. **Настройте параметры** (или оставьте по умолчанию).
4. **Введите текст** в текстовое поле.
5. Нажмите **Embed text**.
6. В строке состояния появятся размер и CRC32 – **скопируйте параметры** для будущего извлечения.

### Извлечение

1. **Входное изображение** – загрузите стего-изображение.
2. **Установите точно такие же параметры**, которые использовались при внедрении (биты, каналы, seed, режим, параметры Smart).
3. **Размер полезной нагрузки** – введите исходный размер (в байтах).
4. Нажмите **Extract text** – текст появится в текстовом поле.

## Режимы предпросмотра

- **Оригинал** – показывает загруженное изображение.
- **Наложение дисперсии** – визуализирует значения дисперсии (только в режиме Smart).
- **Сравнение** – показывает оригинал и изменённое изображение рядом, выделяет изменённые пиксели.

Кнопка **Авто** предлагает порог (70-й процентиль дисперсий) для загруженного изображения.
