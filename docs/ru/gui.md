# Использование графического интерфейса

## Расположение окна

- **Левая панель**: выбор изображений, полезная нагрузка, панель шифрования, параметры стеганографии, кнопки действий.
- **Правая панель**: предпросмотр изображения с различными режимами отображения.

Окно разделено на две вкладки — **Встраивание** и **Извлечение** — каждая со своим набором параметров.

## Пошаговое руководство

### Внедрение

1. **Входное изображение** – выберите файл PNG/BMP/TIFF/PPM.
2. **Выходное изображение** – укажите куда сохранить стего-изображение.
3. **Текстовые данные** – введите текст для сокрытия.
4. **Шифрование** (необязательно) – раскройте панель, поставьте галочку, введите пароль дважды, выберите шифр и KDF. Значения по умолчанию (`AES-256-GCM`, `PBKDF2-HMAC-SHA256`, 100 000 итераций) безопасны.
5. **Настройте параметры стеганографии** (или оставьте по умолчанию).
6. Нажмите **Встроить**.
7. В строке состояния появятся размер и CRC32. Строка **Использовано** над параметрами показывает, какую часть ёмкости займёт нагрузка — включая накладные расходы шифрования.

### Извлечение

1. **Входное изображение** – загрузите стего-изображение.
2. **Установите точно такие же параметры стеганографии**, которые использовались при внедрении (биты, каналы, seed, режим, параметры Smart).
3. **Размер полезной нагрузки** — определяется автоматически, если при встраивании был записан заголовок размера. Если нет — введите размер вручную.
4. **Расшифровка** (необязательно, если данные были зашифрованы) – раскройте панель, поставьте галочку, введите пароль.
5. Нажмите **Извлечь** – текст появится в текстовом поле.

### Копирование параметров

На обеих вкладках есть кнопки **Копировать параметры** / **Вставить параметры**. Строка содержит все параметры стеганографии, режим заголовка размера и настройки шифра/KDF — но **никогда не содержит пароль**. Используйте это, чтобы перенести конфигурацию из вкладки встраивания во вкладку извлечения без ошибок.

## Панель шифрования

**Шифрование (вкладка Встраивание)**:

- Галочка включения шифрования.
- Поля пароля и подтверждения с кнопкой показа (👁).
- **Шифр** — AES-128-GCM, AES-256-GCM, ChaCha20-Poly1305, AES-256-CBC, AES-256-CTR.
- **KDF** — PBKDF2-HMAC-SHA256/512, scrypt.
- **Число итераций KDF** — от 1000 до 100 000 000, по умолчанию 100 000.
- Краткая подсказка про хранение пароля.

**Расшифровка (вкладка Извлечение)**:

- Только галочка и поле пароля. Шифр, KDF и число итераций берутся из самого контейнера.

Пароли **никогда не сохраняются в `QSettings`** и очищаются из поля подтверждения после успешного встраивания.

## Режимы предпросмотра

- **Оригинал** – показывает загруженное изображение.
- **Наложение дисперсии** – визуализирует значения дисперсии (только в режиме Smart).
- **Сравнение** – показывает оригинал и изменённое изображение рядом, выделяет изменённые пиксели.

Кнопка **Авто** предлагает порог (70-й процентиль дисперсий) для загруженного изображения.

## Настройки

Откройте **Настройки** на панели инструментов:

- **Тема** (Светлая / Тёмная).
- **Язык** (English / Русский) – требует перезапуска.
- **Прозрачность наложения** для режима дисперсии.
- **Показывать предпросмотр** и **Режим предпросмотра**.
- **Выделять изменения**.
- **Записывать заголовок размера (4 байта)** — см. ниже.

### Заголовок размера

Если включён, при встраивании перед данными записывается 4-байтное big-endian число — длина нагрузки. На вкладке извлечения этот режим отображается в виде read-only галочки; если заголовка нет, поле *Размер данных (байт)* становится доступным, и размер нужно ввести вручную. Настройка входит в *Копировать параметры*.
