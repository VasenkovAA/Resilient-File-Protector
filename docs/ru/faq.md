# Часто задаваемые вопросы

**В: Почему не работает извлечение?**  
О: Убедитесь, что **все параметры** (биты, каналы, seed, режим, окно, метрика, порог, перемешивание) идентичны тем, что использовались при внедрении. Также проверьте размер полезной нагрузки.

**В: Можно ли использовать JPEG?**  
О: Нет – JPEG с потерями, изменения в LSB будут разрушены при сжатии. Используйте PNG (без потерь).

**В: Что если полезная нагрузка слишком велика?**  
О: Интерфейс покажет ошибку. Увеличьте бит на канал, включите больше каналов или используйте изображение большего размера.

**В: Данные шифруются?**  
О: Пока нет – шифрование будет добавлено на этапе 3. Сейчас стеганография только скрывает факт существования данных.

**В: Как проверить корректность внедрения?**  
О: После внедрения интерфейс показывает CRC32. После извлечения выводится CRC32 извлечённых данных – они должны совпадать.

**В: Можно ли использовать CLI для реальной работы с файлами?**  
О: Пока CLI только выполняет самотестирование. Работа с файлами реализована в Qt GUI.
